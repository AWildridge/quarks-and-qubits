The explorer is an Astro page with an islanded React interface. It keeps the static site payload small while allowing the heatmap, vector view, sliders, and export controls to update in the browser.

The current implementation uses precomputed JSON grids for production mode, basis, and energy combinations. The React island interpolates the active grid for the selected angles and renders both a matrix view and a spin-axis sketch.
