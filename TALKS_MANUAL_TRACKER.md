# Talks Manual Tracker

Last updated: 2026-05-11

This tracker records talks that were manually reconciled against the CV because talk metadata is not reliable enough to regenerate blindly. When the CV is refreshed, compare `src/data/cv.json.talks` against this table. New CV talks should be researched manually, added to `src/content/talks/`, and recorded here.

## Policy

- The talks page should list only talks present in `src/data/cv.json.talks`.
- Do not promote posters into `src/content/talks/`; posters belong in the posters collection.
- Use exact dates only when a public event page or presentation file confirms them.
- If only the year is confirmed, set `displayDate` to the year so the page does not show a fake full date.
- Prefer direct PDF links in `slides`. Use `source` for event pages, abstracts, or timetables.
